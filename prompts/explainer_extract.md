## 任務
找出最值得做視覺說明的地方，最多 {{MAX_COUNT}} 個，分成兩類：

### 1. 航線（route）
受訪者描述了一段實際的航程或路線（從 A 到 B、經過某某海域）。
請列出航線上的關鍵地點及其**經緯度**（你知道的真實座標，十進位度數，
東經／北緯為正，西經／南緯為負）。至少要有 2 個點才算航線。

### 2. 專有名詞（term）
出現了一般觀眾聽不懂的航海術語、船型、賽事、裝備名稱。
挑真的需要解釋的，不要挑常識性的詞（sea、boat、wind 這種不用）。

## 時間點原則
- `at` 要設在**該詞第一次被提到的當下或稍後 1–2 秒**，不要提前爆雷
- 同一個概念只做一次
- 兩個說明之間至少間隔 15 秒

## 輸出格式
只輸出 JSON 陣列：

```
[
  {
    "kind": "route",
    "at": 132.0,
    "title_zh": "澎湖 → 綠島",
    "note_zh": "全程約 180 海里，逆著黑潮北上",
    "waypoints": [
      {"name_zh": "馬公", "name_en": "Magong", "lat": 23.566, "lon": 119.566},
      {"name_zh": "綠島", "name_en": "Ludao", "lat": 22.660, "lon": 121.487}
    ]
  },
  {
    "kind": "term",
    "at": 245.5,
    "term_en": "beam reach",
    "term_zh": "橫風航行",
    "explain_zh": "風從船的正側面吹來，是帆船最快也最穩的航向"
  }
]
```

規則：
- `note_zh` 一句話，25 字以內；`explain_zh` 一到兩句，40 字以內
- 經緯度不確定的地點就不要放進 waypoints；整條航線都不確定就不要輸出這條
- 全部用繁體中文（台灣用語）
- 沒有值得說明的內容就輸出 `[]`
